# Brainsong Today：信源与渠道迁移

## 范围

先恢复旧桌面采集能力，再结合 Omni 的 RSS/Atom 和公众号渠道。七类是发现来源的角度，不是七个推送栏目。最终仍按现有规则统一去重、相关性筛选、排序，最多6条，展会另计。

本轮没有调用模型、智谱搜索或公众号付费接口，没有推送飞书，没有更新正式新闻数据库。

## 恢复与修复

- HTML列表卡片的日期和摘要、嵌套标题、英文日期提取；不借用相邻文章日期。
- 不再只用标题判断；增加标题+列表摘要匹配，缺少摘要或企业垂直来源有限补读，每站最多6篇，先按权重排列。
- 恢复 pubtime、JSON-LD @graph、ScholarlyArticle、time、article-info 等日期信息；新增投中网 releaseTime 和证券时报 detail-info 的适配。
- 同域请求至少间隔1秒，尊重 robots crawl-delay；不绕过登录、验证码和robots限制。
- arXiv按 q-bio.NC / cs.HC / eess.SP / cs.LG 与 EEG / ear-EEG / brain-computer interface 组合查询；查询接口失败时用神经科学、人机交互、信号处理RSS备用；记录备用发生原因。
- 恢复Bing新闻RSS适配，但本地实测返回普通HTML，配置关闭，暂不替代智谱搜索。
- 接入Omni公众号读取适配，不调用其原版AI分析；需要 WECHAT_AUTH_KEY。没有凭证验证，因此默认关闭。关闭额外正文下载API回退。
- 文章失败记录补充原文URL；运行记录增加各来源返回和有日期数量。

## 公众号候选

原Omni已有量子位、机器之心、新智元等6个账号ID。业务上可优先核验脑机新声、脑机接口社区、我爱音频网等垂直账号，但必须先通过授权服务确认账号身份及ID，不能把同名搜狐号当成微信公众号ID。

- 脑机新声公开站点：https://bci-sca.com/
- 我爱音频网：https://www.52audio.com/
- mptext接口为第三方采集服务，不是微信官方API，也不能填智谱密钥。

## 检查证据与边界

运行：`uv run --frozen python tools/probe_sources.py`。该工具只抓公开文本，测试列表解析和每来源1篇详情，不调用AI、不发消息、不写正式SQLite。

第一轮40个配置入口：34个直接请求，5个付费搜索跳过，1个公众号入口等待凭证。复查纠正动脉网导航误识别后，25个直读入口能够解析文章，9个存在失败或限制。25个包括现有14个、正式新增10个、arXiv备用RSS1个。

- reports/2026-09-17/source-probe/results.json：第一轮原始检查，不覆盖。
- reports/2026-09-17/source-recheck/results.json：超时与503复查。
- reports/2026-09-17/finance-recheck/results.json：财经日期修复及动脉网判定纠正。

“可读取”只证明当前本机的一次样本读取，不承诺云服务器可用、长期稳定、内容完整或每次有相关消息。RSS解析数量只计算最近30天，HTML数量是列表条目数量，两者不能直接比较覆盖率。

已有AI批次失败、评分回退和50字摘要质量问题不在这轮采集迁移中修复；不能将本轮采集通过当作完整简报验收通过。
